# UI/UX Review — 2026-05-26

## Summary

DESIGN.md 的 Tokens 已落地到 `app/globals.css`（surface / brand / radius / shadow / type scale 都有 CSS variable）`[SOURCE: app/globals.css:50-101,138-167]`，但 component / page 端的對齊度只到約 20% — 144 處仍用 legacy `text-(xs|sm|...)` scale、37 處用 token；圓角頻繁出現禁用值 `rounded-2xl / rounded-full / rounded-lg`，照片優先卡片被「圖片暫時隱藏」整段註解掉 `[SOURCE: components/menu-item-card.tsx:41-49]`。Photography-first 規則目前等於沒實作；多處 admin / orders 直接用 raw Tailwind palette（`bg-blue-50`、`text-yellow-600`）無對應 token 與 dark 樣式。

## Critical（用戶感知問題 / 嚴重不對齊）

- **餐點卡圖片被整段註解，photography-first 規則完全沒落地** `[SOURCE: components/menu-item-card.tsx:41-49]`
  - DESIGN.md 規定餐點卡 1:1 圖片佔卡片 ≥ 65% `[SOURCE: DESIGN.md:46-47,200-213,242-246]`；目前 `MenuItemCard` 只有純文字，圖片區塊被註解掉
  - 修法：移除註解，加回 `AspectRatio ratio={1}`、`bg-surface-placeholder`、`rounded-r-card`，沒圖時用 placeholder 色塊不要 spinner；`Image` 加 `sizes` prop 避免 layout shift

- **`text-md` 是不存在的 class，5 處字體完全沒套用 size** `[SOURCE: app/menu/[id]/page.tsx:57,62,69, app/admin/vendors/page.tsx:74, app/admin/vendors/[id]/area-editor.tsx:58]`
  - Tailwind v4 沒有 `text-md`（只有 `text-base`），globals.css 也沒定義 `--text-md`，這些 element 會 fallback 到 inherit
  - 修法：商家詳情頁 ratings 改 `text-meta text-muted-foreground`、tags 改 `text-caption`、description 改 `text-body text-muted-foreground`；admin vendor 標題改 `text-heading-sm font-semibold`

- **`/menu/[id]` hero 用舊 token，跟 DESIGN.md 整套衝突** `[SOURCE: app/menu/[id]/page.tsx:44-69]`
  - 用 `bg-muted rounded-lg`（應 `bg-surface-placeholder rounded-card`）、`text-4xl font-bold`（DESIGN.md 規定餐點 / 商家標題用 `text-heading-sm` 16px，且 `display` 28px 只給 hero，4xl/`text-4xl` = 36px 超出 type scale）`[SOURCE: DESIGN.md:88-105]`、`rounded-full`（禁用值，應 `rounded-pill`）`[SOURCE: DESIGN.md:138-150]`
  - 修法：hero `bg-surface-placeholder rounded-card`、標題 `text-display`（hero 例外允許）或 `text-heading`、暫停營業 chip `rounded-pill text-caption`

- **Status chip 用 raw Tailwind palette，無 dark mode 變體** `[SOURCE: app/admin/vendors/page.tsx:5-9, app/admin/vendors/[id]/page.tsx:9-13, app/admin/users/user-role-row.tsx:41-44,52-56, app/orders/order-list.tsx:20-26, app/vendor/orders/page.tsx:107]`
  - DESIGN.md 規定 destructive/success 走 token，brand color heartbeat 限定四種場景 `[SOURCE: DESIGN.md:54-78,234-238]`；目前 status badge 出現 `bg-blue-50 text-blue-600`、`bg-yellow-50 text-yellow-600` 沒 dark variant，dark mode 下 50 series 會白底配淡藍字幾乎不可讀
  - 修法：定義 status token（pending/approved/rejected/in-progress）或統一用 `bg-muted text-muted-foreground` + 圖示區別；至少參考 `app/vendor/menu/menu-item-card.tsx:38,41` 補 `dark:` 對應

## Important（DESIGN.md drift / 易踩雷）

- **圓角 7 種具名 token 沒用，全用 shadcn `rounded-(lg|md|sm|2xl|full)`** `[SOURCE: app/admin/loading.tsx:10,18,25, app/admin/vendors/page.tsx:37,44,71,76, app/orders/order-list.tsx:46,52, app/cart/page.tsx:49, app/menu/[id]/loading.tsx:8,17,24, components/ui/button.tsx:8, components/ui/input.tsx:11, components/ui/select.tsx:47,72]`
  - 全 codebase 出現 `rounded-2xl`、`rounded-lg`、`rounded-full`，DESIGN.md 明確禁用 6/10/12/24px 並要求七種具名 `[SOURCE: DESIGN.md:138-150]`
  - 修法：批量替換 — 卡片 `rounded-card`、tag/chip `rounded-pill`、status badge `rounded-badge`、modal `rounded-modal`、icon button `rounded-icon`；ui/input.tsx / ui/button.tsx default rounded 改成 `rounded-button`（8px = 0.5rem）、ui/select trigger 改 `rounded-input`

- **`<Skeleton>` 底色用 `bg-muted` 而非 `bg-surface-loader`** `[SOURCE: components/ui/skeleton.tsx:7]`
  - DESIGN.md 定義 surface 階層 placeholder（圖片載入前）vs loader（skeleton 動畫底）兩種不同色 `[SOURCE: DESIGN.md:55-59,138-148]`
  - 修法：`className={cn("animate-pulse rounded-md bg-surface-loader", className)}`；同時 `rounded-md` 不在七種具名，可直接拿掉、由 caller 指定 `rounded-card`/`rounded-input`

- **`<Header>` 用 `bg-card/80 backdrop-blur-sm` 自己組，而非 `shadow-sticky` 規範** `[SOURCE: components/header.tsx:31]`
  - DESIGN.md 規 sticky header scroll 後加 `shadow-sticky` `[SOURCE: DESIGN.md:161,177]`；目前用 backdrop blur + border-b
  - 修法：移除 `/80 backdrop-blur-sm`，scroll detect 後加 `shadow-sticky`；或保留靜態 `border-b` 一致，但拿掉 `bg-card/80` 因為 DESIGN.md 規 Header 是 surface level 2 純 card

- **`text-md`、`text-4xl`、`text-6xl`、`text-2xl` 等 legacy class 144 處 vs token 37 處** `[SOURCE: app/cart/page.tsx:38,46,53,62,63,77, app/orders/order-list.tsx:46,52, app/admin/page.tsx:16, app/admin/stat-card.tsx:29-31, app/not-found.tsx:8, app/error.tsx:14, app/global-error.tsx:13]`
  - DESIGN.md 規定 7 個 typography token（caption/meta/body/body-strong/heading-sm/heading/display）`[SOURCE: DESIGN.md:88-105]`
  - 修法：grep 全 codebase `text-(xs|sm|base|lg|xl|2xl|3xl|4xl|5xl|6xl)`、`font-bold`，逐一替換成 token；`font-bold` (700) 規範允許但 DESIGN.md 偏好標題 `font-semibold` (600) `[SOURCE: DESIGN.md:88-105,100-103]`

- **`bg-amber-700` / `bg-amber-800` / `text-white` 在 slot-banner 違反 brand 限制** `[SOURCE: app/vendor/menu/slot-banner.tsx:52]`
  - 警告 banner 的 CTA 應該維持黑底白字 `Button variant="default"`（DESIGN.md primary CTA 規定）`[SOURCE: DESIGN.md:71-77]`，不應在 banner 內染色 amber
  - 修法：banner 容器染 amber 可以（warning state），CTA button 拿掉 `bg-amber-*` 改用 default variant

- **`add-to-order-dialog.tsx` 用 `style={{ borderColor: "currentColor" }}` 內聯樣式** `[SOURCE: app/menu/[id]/add-to-order-dialog.tsx:153-154]`
  - 違反 token 系統，selected state 應走 token
  - 修法：改 `aria-checked` + `data-state` selector + `border-primary` / `border-brand` token

- **Recommendation accent stripe 用 `bg-brand rounded-full`，size 寫死 `w-1 h-5`** `[SOURCE: components/recommendation-section.tsx:16]`
  - DESIGN.md 推薦區可用 brand `[SOURCE: DESIGN.md:222-238]`，但 stripe 形狀不在 7 種具名 — 可接受但 `h-5` (20px) 跟 `heading` line-height 對齊不準
  - 修法：用 `h-[1.25em]` 跟 heading line-height 綁定；或改成放 brand emoji / icon 不用條狀
